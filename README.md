# Дашборд вовлечённости в тренировки

Интерактивный статический дашборд по программе онлайн-тренировок за 10 недель.

## Состав проекта

- `index.html` — страница дашборда;
- `style.css` — оформление;
- `app.js` — графики, фильтры и взаимодействия;
- `data.json` — подготовленные данные для 80 тренировок и 3 755 просмотров;
- `Онлайн-тренировки, 10 недель.xlsx` — исходные данные.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Открыть: `http://127.0.0.1:8000`.

## GitHub Pages
